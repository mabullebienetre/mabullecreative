# Ma Bulle de Bien-Être — site prêt pour GitHub Pages

## Contenu
- `index.html` : page complète du site.
- `images/` : images extraites du fichier HTML et référencées localement.

## Publication sur GitHub Pages
1. Décompressez cette archive sur votre Mac.
2. Dans votre dépôt GitHub, téléversez `index.html` et le dossier `images` (avec son contenu) à la racine du dépôt.
3. Dans GitHub, ouvrez Settings → Pages et choisissez la branche principale (`main`) et le dossier `/(root)`, puis enregistrez.
4. Attendez la publication et ouvrez l’adresse fournie par GitHub Pages.

Gardez une copie de sauvegarde de votre site original. Les images ont été extraites du HTML et les références intégrées ont été remplacées par des chemins relatifs `images/photo-XXX.ext`.
